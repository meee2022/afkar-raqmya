# عالم الكود · Code World — دليل الهوية

الاسم التجاري المعتمد من وزارة التجارة والصناعة (قطر) بتاريخ 19/11/2026.

## الشعار

رمز الكرة الأرضية بخطوط ذهبية وفي قلبها رمز الكود `</>`، وبجانبه **CODE WORLD** بخط كبير و«عالم الكود» بخط أصغر تحته.

| الملف | الاستخدام |
|---|---|
| `logo/code-world-logo-light.png` | الشعار على الخلفيات الفاتحة (شفاف) |
| `logo/code-world-logo-dark.png` | الشعار على الخلفيات الغامقة والعنابي (شفاف) |
| `logo/code-world-logo-on-cream.png` | الشعار على خلفية كريمية جاهزة |
| `logo/code-world-mark.png` | الرمز وحده 1024×1024 (شفاف) |
| `logo/code-world-avatar.png` | صورة حساب إنستجرام وفيسبوك 1080×1080 |
| `logo/facebook-cover.png` | غلاف صفحة فيسبوك 1640×624 |
| `logo/og-image.png` | صورة المشاركة عند إرسال رابط الموقع 1200×630 |
| `logo/cw-globe.svg` · `logo/cw-globe-ondark.svg` | الرمز Vector للموقع والطباعة |

## الخطوط

- **CODE WORLD:** Sora ExtraBold (800)
- **عالم الكود:** Readex Pro SemiBold (600)
- **نصوص الموقع:** Tajawal

## قواعد

- يظهر الاسمان العربي والإنجليزي معًا دائمًا.
- الإنجليزي كبير، والعربي أصغر تحته.
- على الخلفيات الغامقة استخدم نسخة `dark` أو `ondark`.
