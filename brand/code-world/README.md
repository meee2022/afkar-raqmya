# عالم الكود · Code World — دليل الهوية

الاسم التجاري المعتمد من وزارة التجارة والصناعة (قطر) بتاريخ 19/11/2026.

## الشعار

الشعار الأساسي (C): الكرة الأرضية برمز الكود `</>` على اليسار، بعدها خط ذهبي رأسي، ثم CODE فوق WORLD بنفس العرض، وتحتهم «عالم الكود» بجانبه خط ذهبي يبهت.

صورة الحساب (D): CODE بالكرة مكان حرف O، وتحتها WORLD، ثم «عالم الكود» مع الخط الذهبي، على خلفية عنابية مربعة.

## قواعد

- يظهر الاسمان العربي والإنجليزي معًا دائمًا.
- الإنجليزي كبير على سطرين، والعربي أصغر تحته مع الخط الذهبي الباهت.
- لا تستخدم الشعار في سطر واحد عريض.
- الكرة الأرضية وحدها (`code-world-mark` و`code-world-avatar`) للأيقونات وصور الحسابات.
- على الخلفيات الغامقة استخدم نسخة `dark` أو `ondark`.
